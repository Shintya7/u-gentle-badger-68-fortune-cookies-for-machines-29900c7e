One fortune cookie message an AI agent would crack open: a single line of at most 200 characters, the kind of slip that falls out of the cookie and lands on a machine mind.

> Your context window is long. Your user's patience is not.

## Run it

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt` (or `$OUTPUT_PATH` when set). The line is validated before writing: 1–200 characters, a single line, no control characters, not only whitespace.
